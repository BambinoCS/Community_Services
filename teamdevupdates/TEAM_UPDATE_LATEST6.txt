IMPORTANT INTEGRATION DECISIONS
1. The current service form was adapted; the old backup modal was not restored.
2. Assistant files keep the team's hyphenated names. Shared scripts load before
   the auth guard so authenticated events initialize the lists reliably.
3. The backup SQL is now 005_service_request_workflow.sql, after the team's 004.
   Do NOT apply the old backup 004_service_request_workflow.sql to this version.
4. Service creation/status changes use secure RPCs. Resource creation retains
   column-restricted INSERT plus own-user/community/open/resource RLS checks.
   This avoids breaking Request New Items when service writes are restricted.
5. Open item cancellation uses cancel_resource_request. Direct request/assignment
   status updates are denied, including attempts to forge completed service work.
6. Legacy service category values remain supported alongside current team values.
7. Updates 4 and 5 were restored as historical records. Their old Git status and
   deployment instructions are not current; use this update and README.md.
