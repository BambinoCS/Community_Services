6. SUPABASE DATABASE MIGRATION
======================================================================

Created:

- shared/supabase/migrations/004_request_help_fields.sql

The migration adds structured optional fields for the Request Help/report
workflows.

public.requests:
- item_name text
- quantity integer
- problems_addressed text[]

Validation:
- quantity is allowed to be NULL
- when supplied, quantity must be >= 1

public.reports:
- urgency text
- additional_info text

Indexes:
- requests_item_name_idx
- reports_urgency_idx

The migration uses IF NOT EXISTS for the added columns/indexes.

IMPORTANT DEPLOYMENT NOTE:
The migration is committed to Git as a project migration, but a normal
git push does not automatically apply SQL to the Supabase database unless
the team's Supabase migration/deployment process does so separately.
